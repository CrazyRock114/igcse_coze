# Classroom Hook Bank

A teacher's-eye mirror of `src/content/classroom-stories.ts`. The TS file
is structured for the website to query; this file is for you, when you're
planning the next lesson and want to scan 30+ proven hooks in one screen.

> **Reading the table**:
> - `Q` = quality: `A` (essential) / `B` (useful) / `C` (weak)
> - `Source` = YYYY-MM-DD + line number in the original transcript
> - `Where it lands` = which syllabus statement or section it best anchors
> - `30-sec` = the one-sentence version you can use in a lesson

## 评分标准

- **A 必收**：能独立撑起 1-2 分钟讲解，事实正确，记忆点强
- **B 可用**：可作为辅助例子，但需要教师再加工
- **C 弱**：只有 one-liner 价值，课堂时间紧可舍弃

---

## 怎么用这个库

1. **下节课前**打开本文件，看你的目标 lesson 区段，从 A 钩子里挑 1-2 个
2. **开场用**（0-3 min）：选一个最直观的钩子，把学生注意力拉过来
3. **穿插用**（讲到 syllabus statement 时）：选能锚定该 statement 的钩子
4. **收尾用**（最后 2 min）：回到开场钩子，"所以这个现象其实就是 X 的原因"
5. **新钩子**：下次上课有新的精彩钩子，跟我说"今天讲了一个 XXX 的故事"，我帮你加进去
